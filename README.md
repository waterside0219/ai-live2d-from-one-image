# 纯 AI 做 Live2D：从一张图到手机和桌宠

只用 AI agent，把**一张平面角色立绘**做成能动的 Live2D 模型，再装进**安卓手机网页**和 **Windows 透明桌宠**（字幕、出声、嘴型、按住侧键说话）。全程没有用 Cubism Editor，也没有请绑模师。

这是我们真实做过一遍的记录：既有可照着做的教程，也有走过的弯路。**写给第一次做的人。**

## 你需要准备的三样公开资源

| 资源 | 用途 |
|---|---|
| [fifteen42/live2d-from-art](https://github.com/fifteen42/live2d-from-art) | 博主的 skill：从原画做 Live2D 的流程和参考代码，里面附带 MIT 许可的 `py-moc3` 序列化器（用来直接写 MOC3） |
| [Live2D Cubism Core](https://www.live2d.com/en/sdk/download/web/) | 官方运行库（专有，需按官方条款自己下载），负责加载和计算模型 |
| [Live2D/CubismWebFramework](https://github.com/Live2D/CubismWebFramework/tree/5-r.2) 5-r.2 | 官方网页框架，负责动作、物理（头发和耳朵的惯性） |

另外要有：一个能干重活的 agent、一个专门验收的 agent、Python 3、Node、ffmpeg，以及一个图像生成工具（只用来补画被挡住的部分）。完整的依赖清单见[教程第 0 步](docs/01-教程.md#0-准备与原图检查)。

## 先看这三条

1. **原图要用“文件”方式发送，必须是透明底 PNG，收到后先检查 alpha（透明度通道）。** 按“照片”发送的图会被压成 JPG，透明背景变黑，后面的细节就没法抠了。
2. **手里已经有定稿立绘时，看得见的部分直接用原图像素，只补画被挡住的部分。** 不要让 AI 把每个部件重画一遍，那样会变脸。
3. **验收要让模型动起来看，在真机上按实际大小看，并且用运行时真实会同时出现的参数组合去看。** 没全部测过，就不说“好了”。
