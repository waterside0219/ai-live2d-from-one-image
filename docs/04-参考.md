# 参考速查

这里只放查表用的内容。为什么这样做，请看[教程](01-教程.md)。

## 参数命名

使用 Live2D 标准参数名，这样 VTube Studio 这类软件能自动映射。**L/R 指角色自己的左右，和画面上的左右相反。** 素材文件名里的 L/R 是画面左右，建模时要换过来（见[教程 7.2](01-教程.md#72-分层清单示例匿名字段名和我们真实构建时用的一致)）。

| 类别 | 参数 | 说明 |
|---|---|---|
| 头 | `ParamAngleX/Y/Z` | 浅幅转头、点头、侧倾 |
| 眼 | `ParamEyeLOpen/ROpen` | 左右眼分别开合 |
| 眼 | `ParamEyeLSmile/RSmile` | 笑眼（下眼睑微微抬起） |
| 眼 | `ParamEyeBallX/Y` | 视线方向 |
| 眉 | `ParamBrowLY/RY` | 眉毛上下 |
| 嘴 | `ParamMouthOpenY`、`ParamMouthForm` | 嘴的开合；嘴形（-1 抿嘴，0 原样，1 微笑） |
| 身体 | `ParamBreath` | 呼吸 |
| 耳（自定义） | `ParamEarL/R` | **物理输出**，不要直接写入 |
| 耳（自定义） | `ParamEarTouchL/R` | 摸耳输入，每只耳朵各自一个 |
| 头发（自定义） | `ParamHairFrontL/C/R`、`ParamHairSideL/R`、`ParamHairBack` | **物理输出** |

我们最终一共用了 24 个参数。如果还需要更多，可以继续按标准名扩展：`ParamBodyAngleX/Y/Z`、`ParamBrowLForm/RForm`、`ParamCheek`；配件开关用 `ParamAcc<名字>`（0 隐藏 / 1 显示），整套换装用 `ParamOutfit`（按整数段切换）。

## 物理分组

| 组 | 输入 | 输出 |
|---|---|---|
| 头发 ×6 | AngleX（65%，位移）+ AngleZ（35%，角度） | 前发左/中/右、侧发左/右、后发 |
| 耳朵 ×2 | 各自只读 `ParamEarTouchL` 或 `ParamEarTouchR` | `ParamEarL` / `ParamEarR` |

发根固定，发梢的摆幅最大；各组的延迟稍有不同。摸耳的脉冲参数：0.5 秒升到峰值，1.3 秒回到 0；耳朵约 0.45 秒展开，2–3 秒回稳。

## 口型常数

| 量 | 值 |
|---|---|
| 噪声阈值 | 0.012 |
| 增益 | 4.5 |
| 张嘴上限 | 0.85 |
| 张嘴 / 闭嘴时间常数 | 35ms / 75ms |
| AnalyserNode fftSize | 1024 |
| 无音频节点时的包络分块 | 20ms |

```js
const target = Math.min(0.85, Math.max(0, (rms - 0.012) * 4.5));
mouth += (target - mouth) * (1 - Math.exp(-dt / (target > mouth ? 0.035 : 0.075)));
set('ParamMouthOpenY', mouth);
set('ParamMouthForm', 0.4 * mouth / 0.85);
set('ParamEyeLSmile', 0.08 * mouth / 0.85);
set('ParamEyeRSmile', 0.08 * mouth / 0.85);
```

## 排查：是模型的问题，还是渲染的问题

| 现象 | 模型方面的原因 | 渲染方面的原因 |
|---|---|---|
| 嘴像开了个口子 | 只有 `ParamMouthOpenY`，没有 `ParamMouthForm`；口腔只是一块补画 | 说话时用正弦函数机械地开合，没有跟着真实音量 |
| 眼睛没有神 | 虹膜太小、没有独立的高光层；没有笑眼或眼睑形变参数 | 眼球只跟着手指或人脸位置走，没有微小的随机游移 |
| 耳朵和头发动得僵 | 头发片数太少，几片共用一个摆动参数；没有 physics3.json | 自己写的 WebGL 只跑 Core，没有官方 Framework，所以物理算不出来；待机曲线用线性插值，动作匀速，显得机械 |
| 夜间画面发灰 | — | 在模型上叠了一层暗色滤镜 |

## 博主的做法（我们的出发点）

博主让 Astra 先**生成一张“为拆件而画”的原创立绘**（透明底、尺寸很大、能拆的部件都尽量拆细），拆成 42 层：头发约 15 片，虹膜单独一层，眼白、上下睫毛、闭眼线也各自分开。然后导入 VTube Studio 做面部捕捉。第一版效果“有点恐怖”：眼睛被压扁了，眉眼动作也不协调。之后让 Astra 继续调整，才能转头、眨眼、张嘴笑，头发也能一束一束地晃。**我们手里是一张定稿立绘，起点不一样**，所以不能整套照搬（见[复盘坑2](02-踩坑复盘.md#坑2-定稿立绘逐件-ai-重画变了脸)）。

## 换装和配件

**画新衣服的要求**
1. 画布和原图完全一样大，直接在原图上叠一层画。人物的位置、肩线、脖子、领口都不动。
2. 用透明底的 PNG 或 PSD，不要黑底或白底，也不要 JPG。
3. 按层分开：衣服后片、衣服主体、领子（单独一层，转头时要稳）、左袖、右袖、小配饰。
4. 被挡住的地方也要画完整，比如被长发盖住的肩膀和胸前，否则头发一晃就会露出空洞。
5. 脸、耳朵、眼睛、眼镜、发型、脖子都不能动，新衣服只换脖子以下。

**接进模型的三种方法（从简单到复杂）**
- A 换贴图：形状基本不变，只换颜色或花纹，直接替换衣服那块贴图，网格不动。
- B 加部件和开关：形状变了（比如加了外套），作为新部件加进模型，绑定到身体和呼吸的形变上，用 `ParamOutfit` 或 `ParamAcc…` 切换。
- C 新建一套：大改造型时，按整套流程重做身体部分。

**头饰**：做成独立部件，挂在头部的形变上（跟着 Angle X/Y/Z 一起动），转头时就不会飘。先想好耳朵怎么处理：是从帽子里穿出来，还是被帽子压住。如果只是想快速出个效果，也可以每帧按脸部顶点的位置贴一张 PNG，效果比真正绑定差一点，但不用改模型。
