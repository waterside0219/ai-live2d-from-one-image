## 二、工具链怎么用、有什么限制

- **live2d-from-art**（博主的 skill，本机快照 `~/.codex/skills/live2d-from-art/`）：不是一键生成器，是"一次案例的流程+代码"，每个角色都要改坐标、蒙版、网格、参数。顺序：建基准 → 静态重组像原图 → 先静态 MOC3 再逐个加参数 → 网页里用真 Cubism Core 看 → 动作润色 → 交付。
- **直接写 MOC3**（py-moc3，MIT）：不经过 Cubism Editor，**没有 .cmo3**，以后不能用官方编辑器打开改。关键形（keyform）按参数轴展开，轴越多组合越多，别把每个参数绑到每片网格。
- **ImageGen 局部补绘**：只补"动的时候会露出来"的地方（刘海下额头、闭眼皮、口腔、头发后面的衣服），用原图坐标裁切采用，**绝不能用生成图替换可见的脸**（会变脸）。提示词范本在 `docs/IMAGEGEN.md`。
- **Cubism Core**：从官方地址下载，私人使用，不随包分发。
- **物理**：`physics3.json` 是官方的头发/耳朵惯性摆动配置，由运行端（官方 Cubism Web Framework）计算。只有 Core 没有 Framework 时**物理不会生效**。
- **VTube Studio**：网页能跑 ≠ VTS 能用，要真装真测。

## 三、Astra 做 V1 的实际做法和踩过的坑

V1：25 层 / 25 网格 / 4527 顶点 / 12 参数；`EyeL/ROpen, EyeBallX/Y, MouthOpenY, AngleX/Y/Z, Breath, EarL/R, HairSwing`。次级动作是14秒循环关键帧（`idle.motion3.json`，全是线性段），**不是物理**。

踩过的坑（见 `evidence/*-red.log`）：
1. 渲染器没处理 Core 的 Y/UV 翻转 → 加载成功但画面空白。
2. 闭眼纹理错位、肩后隐藏重叠露底、可动头发带了衣服像素。
3. 原图是带黑/黄绿边的 JPG：去底误伤黑眼线、头顶发圈；细发丝边缘只能约1px收边，找不回原始 alpha。
4. 报告绑定旧模型哈希 → 测试要拒绝错配证据。
5. 头顶耳尖贴近画布边，大角度转头会裁边。
6. 嘴只有开合，眼睛虹膜很小、没拆高光，头发只有4片且共用一个摆动参数。

阿年 10-26 看完的真实观感：**嘴说话像开了个口子；眼睛没有眼波流转；耳朵、头发动得不自然。**

## 四、模型问题 vs 渲染问题（以后排查先分清）

| 现象 | 模型原因 | 手机渲染原因（`android-body/face/face.js` + `live2d-pose.js`） |
|---|---|---|
| 嘴像开口子 | 只有 `ParamMouthOpenY`，没有嘴形（`ParamMouthForm`），口腔是一块补绘 | 说话时用 `sin(now/93)` 机械开合，不看真实音量 |
| 没眼波 | 虹膜很小、没有独立高光层；没有眼睛微笑/眼睑形变参数 | 眼球只跟手指/人脸位置，没有微小随机游移（saccade） |
| 耳朵头发僵 | 头发只4片、一个 `HairSwing` 同向摆；耳朵 ±5° 很小；无 physics3.json | 自写 WebGL 只用 Core，没有官方 Framework，物理无法计算；idle 曲线线性插值，动作匀速机械 |
| 夜间发灰（已修） | — | 曾在模型上盖暗滤镜 |

## 五、参数命名规范

用 Live2D 标准名，VTS 能自动映射：`ParamAngleX/Y/Z, ParamBodyAngleX/Y/Z, ParamBreath, ParamEyeLOpen/ROpen, ParamEyeLSmile/RSmile, ParamEyeBallX/Y, ParamBrowLY/RY, ParamBrowLForm/RForm, ParamMouthOpenY, ParamMouthForm, ParamCheek`。
自定义：耳朵 `ParamEarL/R`，头发按组 `ParamHairFront, ParamHairSide, ParamHairBack`（物理输出参数），配件开关 `ParamAcc<名字>`（0隐藏/1显示），衣服套装 `ParamOutfit`（整数段切换）。L/R 一律指**角色自己的**左右。

## 六、换季节衣服 / 头饰（阿年自己画衣服时照这个画）

### 画新衣服的要求
1. **画布**：和原图完全一样大（960×1280），**直接在原图上叠一层画**，人物位置、肩线、脖子、领口不动，这样新衣服才能对准原来的身体。
2. **透明底**：导出 PNG（带透明）或 PSD，**不要黑底/白底**，不要 JPG。
3. **分层**（每层一个图层，名字写中文也行）：
   - 衣服后片（领子后面、肩后面露出来的部分）
   - 衣服主体（前片）
   - 领子（单独，转头时领子要稳）
   - 左袖、右袖（各一层）
   - 配饰（扣子、项链、徽章这种小东西单独一层）
4. **被挡住的地方也要画完整**：长发盖住的肩膀、胸前那部分衣服要画出来（不用精细，颜色和褶皱接得上就行），不然头发一晃就露出空洞。
5. **不能动的部件**：脸、耳朵、眼睛、眼镜、发型、脖子的位置和形状。新衣服只换"脖子以下"。
6. 风格：线条粗细、上色方式（赛璐璐/阴影两层）尽量跟原图一致，颜色可以随季节换。

### 接进模型的三种做法（从简到繁）
- **A 换贴图**：新衣服形状和原衣服基本一样（只换颜色花纹）→ 直接替换 BodyShirt 那块贴图，网格不动。最快。
- **B 加部件+开关**：形状不一样（比如加了外套、围巾）→ 新衣服作为新部件加进模型，绑同一个身体/呼吸变形，用 `ParamOutfit` 或 `ParamAcc...` 切换显示。
- **C 新建套装模型**：大改（比如古装、全换造型）→ 按本流程重做身体部分。

### 头饰 / 眼镜 / 万圣节帽
- 配件做成独立部件，**挂在头部变形（跟 Angle X/Y/Z 一起动）**上，这样转头、点头时帽子跟着头走，不会飘。
- 帽子要压在头发上面但耳朵怎么处理要先定：猫耳从帽子里穿出来（帽子画两个洞）或者帽子压住耳朵（耳朵动画关掉）。
- 用开关参数 `ParamAcc<名字>` 控制显示，手机设置页里做开关。
- 只想快速出效果（比如万圣节当天）：手机端也可以用"贴片"方式——按模型脸部顶点位置每帧把一张 PNG 帽子贴在头顶，跟着头动。效果比真绑定差一点，但不用改模型。

## 七、手机端渲染要求（android-body 接入时）

1. 用**官方 Cubism Web Framework**（或成熟的 pixi-live2d-display 等）加载 model3.json，让 `physics3.json`、motion 的贝塞尔/淡入淡出、表情 exp3 都正确生效；不要再用自写 WebGL 只跑 Core。
2. **口型**：按实际播放音频的音量包络驱动 `ParamMouthOpenY`（参考值：阈值0.012、增益4.5、上限0.85、攻击35ms、释放75ms），有 `ParamMouthForm` 时说话带一点微笑形；音频结束回 0。
3. **眼睛**：眨眼不等间隔（2–6秒随机、偶尔连眨），闭合快、睁开稍慢；眼球加微小随机游移（每0.5–2秒小幅换一个注视点），再叠加人脸/触摸视线。
4. **头发耳朵**：交给 physics，输入是头部角度和身体角度；触摸"戳"给一个外力脉冲，不要直接写死参数。
5. 待机：动作之间有停顿，不能所有部件一直正弦摆（原工具反复强调）。
6. Live2D 闲置5分钟回到小眼睛（防烧屏，阿年平时主要用小眼睛）。

## 八、验收清单（按阿年的观感，不是"能加载"）

- [ ] 中性姿态和原图并排同尺度，眼距、眉形、嘴角、眼镜、领口不漂移
- [ ] 说话：嘴随声音大小开合，不是匀速一开一合；闭嘴时口腔不漏
- [ ] 眼睛：有自然的小幅游移，眨眼不压扁虹膜，有高光在动（若做了高光层）
- [ ] 头发：转头/点头后发梢慢半拍甩回，几束之间有先后，不是整片一起动
- [ ] 耳朵：戳一下有弹性地抖，平时偶尔自己动一下
- [ ] 待机看30秒：有停顿，不晕，不像纸片
- [ ] 内屏、外屏（L 形可用区）都看过，字幕不压脸
- [ ] 改前/改后对比录屏各一段给阿年看
- [ ] 没装 VTS 就写"VTS 未验"，不冒充
